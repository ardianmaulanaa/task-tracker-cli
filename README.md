# Task Tracker CLI

Task Tracker CLI is a simple command line application to manage tasks. This project is built with Node.js without external libraries. Tasks are stored in a JSON file.

## Project URL

https://roadmap.sh/projects/task-tracker

## Features

- Add a new task
- List all tasks
- Update a task
- Delete a task
- Mark a task as in-progress
- Mark a task as done
- Store tasks in `tasks.json`

## Tech Stack

- Node.js
- File System module (`fs`)
- JSON
